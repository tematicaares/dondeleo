# Donde Leo - Cocina Mediterránea 🍷🥗

Sitio web oficial de sucursales, ubicación y contacto de **Donde Leo Cocina Mediterránea** (San Salvador, El Salvador).

## 🚀 Cómo ejecutar y desplegar en GitHub

### 🌟 Opción 1: Despliegue gratuito en GitHub Pages (Sin Node ni compilación)
1. Crea un nuevo repositorio en tu cuenta de [GitHub](https://github.com/new) (ej. `donde-leo`).
2. Sube estos archivos con los siguientes comandos en tu terminal:
   ```bash
   git init
   git add .
   git commit -m "feat: lanzamiento sitio web Donde Leo"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/donde-leo.git
   git push -u origin main
   ```
3. En GitHub, ve a **Settings** > **Pages**.
4. En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
5. En **Branch**, elige `main` y la carpeta `/ (root)`. Haz clic en **Save**.
6. En un par de minutos tu sitio web estará disponible públicamente en `https://TU_USUARIO.github.io/donde-leo/`.

---

### 💻 Opción 2: Ejecución Local
- Simplemente haz doble clic sobre el archivo `index.html` para abrirlo en tu navegador favorito (Chrome, Edge, Safari, Firefox).
- O si utilizas Visual Studio Code, haz clic derecho en `index.html` y selecciona **Open with Live Server**.
